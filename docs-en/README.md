# KaOneBlock

> Start with one block and build your own survival island.

KaOneBlock is a OneBlock survival plugin for Spigot and Paper. After a player creates a personal block below their feet, every break produces new content at the same position and advances the player through configurable stages.

## Features

- One personal OneBlock per player
- Configurable block pools, stage order, and goals
- Random loot chests and creature encounters
- Saved block location, stage, and break progress
- Simplified Chinese and English messages
- Optional ItemsAdder custom blocks and items

## Requirements

- Java 17 or newer
- Spigot or Paper 1.18.2 or newer
- ItemsAdder is optional
