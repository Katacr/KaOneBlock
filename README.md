# KaOneBlock

[中文文档](docs/README.md) | [English Documentation](docs-en/README.md)

KaOneBlock is a OneBlock survival plugin for Spigot and Paper servers. Each player can create one personal block, break it repeatedly, progress through configurable stages, and encounter loot chests or creatures along the way.

KaOneBlock 是一款适用于 Spigot 与 Paper 服务器的 OneBlock 生存插件。每位玩家都可以创建一个专属方块，通过反复挖掘推进阶段，并在过程中遇到战利品宝箱或生物。

## Requirements / 运行要求

- Java 17 or newer / Java 17 或更高版本
- Spigot or Paper 1.18.2 or newer / Spigot 或 Paper 1.18.2 及以上版本
- ItemsAdder is optional / ItemsAdder 为可选依赖
