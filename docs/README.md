# KaOneBlock

> 从一个方块开始，逐步完成属于自己的空岛生存。

KaOneBlock 是一款适用于 Spigot 与 Paper 服务器的 OneBlock 生存插件。玩家在脚下生成专属方块后，每次挖掘都会在原位置得到新方块，并随进度进入新的阶段。

## 主要功能

- 每位玩家拥有一个独立的 OneBlock
- 可配置方块池、阶段顺序和阶段目标
- 随机生成战利品宝箱与生物
- 自动保存玩家位置、阶段和挖掘进度
- 支持简体中文和英文消息
- 可选支持 ItemsAdder 自定义方块与物品

## 运行要求

- Java 17 或更高版本
- Spigot 或 Paper 1.18.2 及以上版本
- ItemsAdder（可选）
