# 安装与开始使用

## 安装插件

1. 确认服务器使用 Java 17 或更高版本。
2. 确认服务器核心为 Spigot 或 Paper 1.18.2 及以上版本。
3. 将 `KaOneBlock-版本号.jar` 放入服务器的 `plugins` 文件夹。
4. 完整重启服务器。
5. 在控制台确认 KaOneBlock 已成功启用。

不建议使用服务器的 `/reload` 命令安装或更新插件。插件内的 `/kob reload` 只用于重新读取 KaOneBlock 配置。

## 从旧版本升级

升级前请备份 `plugins/KaOneBlock/`，尤其是 `data.db` 和所有 YAML 配置。

旧版数据库没有保存世界信息。如果玩家原有 OneBlock 不在名为 `world` 的世界，请在**首次启动新版本前**把 `config.yml` 中的 `legacy-world` 改为这些旧方块实际所在的已加载世界。迁移完成后，数据库会记住每个方块的世界。

旧版生物目录 `entitys/` 仍可读取，但建议将自定义文件迁移到 `entities/`。

## 玩家开始游戏

1. 站在准备创建 OneBlock 的位置，确保脚下方块位置是空气。
2. 输入 `/kob start`。
3. 插件会在玩家脚下生成初始方块。
4. 持续挖掘该方块，新的方块、宝箱或生物会按当前阶段配置生成。

每位玩家同一时间只能拥有一个 OneBlock。方块可以位于任意已加载世界，插件会记住其真实世界和坐标。

## 停止并重新开始

输入 `/kob stop` 会移除玩家现有的 OneBlock，并清除本次阶段进度。之后可以在其他位置再次使用 `/kob start`。

如果方块所在世界未加载，插件不会冒险删除其他位置的方块。请先加载对应世界，再执行停止命令。
