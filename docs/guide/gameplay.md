# 玩法说明

## 基本循环

玩家的 OneBlock 被挖掉后，插件会在相同位置生成下一次内容。普通结果来自当前阶段的方块池；特殊结果可能是宝箱或生物。

只有 OneBlock 的所有者可以挖掘它。其他玩家尝试破坏时会被阻止。

## 默认阶段

默认配置包含以下顺序：

1. `normal`：平原阶段
2. `nether`：下界阶段
3. `end`：末地阶段

平原和下界阶段默认各需要挖掘 500 次。末地阶段是默认终局，会持续使用末地方块池。

服务器管理员可以调整每个阶段所需次数、下一阶段、方块权重、宝箱概率和生物概率。

## 宝箱与生物

- 宝箱会替代本次普通方块，并按对应宝箱配置填充奖励。
- 生物事件会在方块上方生成一个生物，同时仍会补充新的 OneBlock。
- 不同阶段可以使用不同的宝箱和生物包。

## 进度保存

插件会保存玩家的 OneBlock 位置、当前阶段和阶段内挖掘次数。正常重启服务器不会重置进度。

使用 `/kob stop` 会主动删除 OneBlock 并重置该玩家进度；管理员使用 `/kob reset-stage` 或 `/kob set` 也会更改阶段进度。
